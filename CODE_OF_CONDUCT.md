# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent. Harassment of any kind
is not accepted.

To report a problem with someone's conduct, write to
hello.liz.zhang@gmail.com. Reports are kept private.
